## About Me

I’m a software engineer driven by systems thinking, performance, and reliability. My work sits at the intersection of backend engineering, product architecture, and AI systems — especially where real-world constraints like latency, scale, and deployment quality matter.

I care deeply about:

- Building systems that hold up under growth
- Reducing unnecessary compute and network overhead
- Designing interfaces and flows that are operationally reliable
- Shipping AI experiences that function with real-world constraints, not just demos

## Core Principles

- Scale: design for the data volume, traffic, and workload the system will face tomorrow
- Efficiency: remove redundant operations, wasted cost, and avoidable latency
- Systems: think in flows, boundaries, and failure modes
- AI: go beyond API usage and engineer inference, orchestration, and resource awareness
- Reliability: build for failures, retries, sync issues, and degraded states
